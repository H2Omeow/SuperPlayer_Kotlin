# v1.1.0-pre

## 音源

- 新增独立的“惜缘惜梦音源”分组。
- 支持在分组内切换酷狗、酷我、网易、QQ、咪咕和 B 站。
- 聚合搜索结果保留实际平台标识，歌曲卡片显示来源。
- 聚合源歌曲接入播放地址、音质查询、下载、歌词、缓存和播放队列。
- 网易云和酷狗原有登录、评论、音质和播放流程保持不变。

## 验证

- `:app:compileDebugKotlin` 通过。
- 线上协议验证：六个平台搜索和 320k 播放地址均返回 `code=200`。

## 限制

- 聚合源依赖第三方 animemusic 服务，服务端暂不提供登录态绑定。
- 聚合源的歌手、专辑分类搜索仍使用原有平台接口，仅歌曲搜索开放聚合平台切换。
