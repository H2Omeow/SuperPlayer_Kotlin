# v1.0.9

## 安装包
- 提供 Android 通用 APK，包含 ARMv7（armeabi-v7a）、ARM64（arm64-v8a）、x86、x86_64，覆盖 ARM / x86 的 32 位与 64 位设备。

## Windows / Linux 桌面预览
- Windows 提供 x64、x86（32 位）、ARM64；Linux 提供 x64、x86、ARM64、ARMv7 hard-float。
- 便携包内置 Java、FFmpeg 和专业音效库；Windows 包可直接运行 **NekoPlayer.exe**，包含搜索、播放队列、本地音乐、歌词、收藏/歌单、登录、Cookie 管理、音质选择、下载与评论。
- 复用原生 API 和 C++ DSP；播放输出为 48 kHz / 16-bit 双声道，下载保留原始音质。
- 初次播放先完整缓冲；酷狗评论点赞/删除仍保持禁用。真实账号授权与各系统音频设备仍需实际使用验收。
- 提供 FFmpeg 对应源码与桌面包 SHA-256 清单，详情见 desktop/README.md。
- Windows/Linux x64、x86、ARM64 与 Windows ARM64 在 CI 执行完整 PCM/DSP 启动自检；Linux ARMv7 在 hosted runner 上完成 ELF 架构校验，真实 ARMv7 播放仍需设备验收。

## 登录与 Cookie 修复
- 酷狗短信发送、令牌刷新改用证书匹配的 HTTPS 登录域名，修复旧域名证书不匹配导致的连接失败。
- 登录界面分别提示安全连接失败、DNS 解析失败、请求超时与平台业务错误，不显示原始请求或账号凭据。
- 设置页与酷狗账号页新增 Cookie 管理：原版/概念版分别查看、复制、导入、清除；内容默认隐藏。
- 导入校验 token、userid 和字段格式，失败时保留原会话；切换账号时清除旧会员凭据，清除操作仅影响所选版本。
- 短信传输验证使用无效号码，确认两种版本均收到平台业务响应，不发送真实短信；实际收码和授权仍需账号验收。

## 原生音乐接口
- 修复酷狗歌曲搜索返回业务错误 152：使用带 Web 签名的 HTTPS 公共目录搜索，保留曲目 hash、专辑与音频 ID，播放/下载仍验证账号权限。
- 网易云与酷狗的现有音乐功能改为 Kotlin/OkHttp 原生直连，不在手机内运行 Node.js。
- 移植加密签名、设备注册、二维码、验证码和会话处理；酷狗原版/概念版隔离设备与登录状态。
- 本站账户中心、云同步和本站评论继续使用本站服务。

## 歌曲评论
- 播放页新增网易云、酷狗、本站三个评论入口，支持分页和楼层查看。
- 网易云、本站在对应账户登录后可发送、回复、点赞/取消点赞及删除本人评论。
- 酷狗接入发送与楼层回复；点赞、删除缺少已验证的接口协议，暂不开放，界面明确说明。
- 跨站点评论先选择对应歌曲，避免同名不同版本误发。
- 本站 SQLite 评论服务验证 Bearer 身份、限制发送频率并校验所有权；删除父评论保留楼层。

## 音质与下载
- 播放前查询当前歌曲音质，优先默认档位，不可用则选择账号可播放的最高档位。
- 下载独立查询并核验下载权限；只显示可下载档位，拒绝试听与静默降档。
- 缓存区分音乐来源、歌曲和实际音质；网络不可用时仅回退完整缓存。
- 音质设置作为偏好，不再按网易云会员等级限制酷狗或单曲的实际档位。

## 验证边界
- 加密签名对照、会话隔离、音质选择与权限过滤、评论解析、本站权限/持久化回归纳入自动测试。
- 公开接口联通测试不发送短信、不创建真实评论，不替代真实账号授权和 Android 真机验收。
- 网易云游客注册的间歇性 code=400 在上游 Node 与原生实现均复现，随后原生重测成功；保留服务端错误，不把失败当作登录成功。
- 酷狗评论点赞、删除尚未完成；会员权限、扫码授权和风控以平台实际响应为准。
