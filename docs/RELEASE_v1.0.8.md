# v1.0.8：酷狗 API 与播放修复

修复专业音效 PCM 缓冲区未消费、输出为空及 JNI 接口不一致的问题。引擎切换改为常驻处理器旁路，保持播放器、队列和播放状态；专业引擎失败时提示错误并原样播放。

- 系统音效按实际初始化与启用结果显示控制项，补齐响度与辅助混响接入。
- 专业音效增加混响空间、阻尼调节，修正 EQ 反馈系数与采样率/声道处理。
- 修复专业 EQ 与低音增益叠加引起的持续过载，按组合频响预留前级余量，保留预设频段之间的相对增益。
- 修复母带内外软限幅叠加压弯波形的问题；改用立即降增益、50ms 峰值保持和平滑释放，减少低频波峰间的反复增益调制。
- 修复母带染色把驱动增益施加到干声以及偏置导致静音非零的问题；湿支路补偿驱动增益，染色前后消除静态偏置与直流。
- 修复从最近任务划掉应用时，非播放状态的媒体服务未按 Media3 前台状态结束而被 Android 判定崩溃并重启的问题。
- 提供 21 组 EQ 预设、20 组签名母带和母带混合比例，完善设置保存与重置。
- 更新 README 与致谢，感谢 [NeteaseCloudMusicApi](https://github.com/Binaryify/NeteaseCloudMusicApi) 和 [KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi)。

验证：19 项 JVM 回归通过，覆盖音效、酷狗认证状态、Cookie 隔离与歌曲标识；2 项 Node 路由测试通过；C++ ASan/UBSan 检查覆盖 20 组预设、6 个采样率、单/双声道、热信号、静音和复合极端增益；新增限幅稳态失真、EQ/低音 THD+N、声道比例及增益恢复回归；真实主机 JNI 测试、debug/release 构建及 debug lint 通过。

**已知限制**：真机播放与系统音效兼容性尚未完成验收。20 组签名母带基于参考参数表实现，仍待原始源码一致性核对；另 14 组基础/声境母带暂不开放。当前为 PCM16 实时 DSP，不提供真实 AI、杜比多声道解码、过采样真峰值保证或 24-bit 升格。

增益余量补偿可能降低增强预设的整体音量。无前视限幅仍会改变突发过载的起始波形；刻意失真风格母带保留非线性染色，自动测试不等同于全部预设的真机听感验收。

## 酷狗 API

- 登录页面仅保留手机号验证码和酷狗 App 扫码，移除手动 Token、QQ AppID 和 QQ 授权入口。
- 修复扫码状态判断、请求缓存和设备 Cookie 丢失；验证码发送成功后才启动倒计时，验证通过后才离开登录页。
- 原版与概念版分别保存会话并请求对应服务；概念版服务独立监听 4001。
- 修正登录刷新、账号、VIP、歌曲取址与歌词接口；保留 hash、专辑标识和歌曲来源，避免将酷狗数字 ID 发送到网易云播放接口。
- 下载索引保存音乐源与 hash，避免不同曲库的相同数字 ID 串用文件。

本次版本为 1.0.8，versionCode 为 11，可覆盖升级 1.0.8-pre。真实账号的短信风控、扫码确认与设备听感仍需实机验证。原生 API 与评论、逐曲音质选择属于后续 1.0.9-pre 范围。
